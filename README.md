# fesa-email-signature

Firma de correo corporativa de FESA con la imagen incrustada en Base64.

## Instalación local

Ejecuta el script desde la carpeta del repositorio:

```bash
./setup.sh
```

Esto copia `firma.html` a `~/Documentos/firma.html` e imprime un mensaje de instalación exitosa.

## Clonar el repositorio

```bash
git clone git@github.com:hguerrero-dev/fesa-email-signature.git
cd fesa-email-signature
./setup.sh
```
